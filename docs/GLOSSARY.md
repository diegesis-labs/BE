# 용어집

이 문서는 백엔드 문서에 등장하는 용어의 뜻을 한곳에 모아 둔 문서입니다. 다른 문서에서 낯선 용어를 만나면 먼저 이 문서를 확인해 주세요. 그리고 새 용어가 생기면 다른 문서에 풀이를 적지 말고 이 문서에 추가해 주세요.

## 책과 관련된 용어

| 용어 | 뜻 |
| --- | --- |
| 문장 번호 | 책 한 권의 모든 문장에 첫 문장부터 차례대로 붙인 번호입니다. 챕터가 바뀌어도 번호는 이어지며, 0부터 시작합니다. 화면 크기나 글꼴과 무관하게 책 속 위치를 가리킬 수 있어서, 프론트엔드와 백엔드가 위치를 주고받는 공통 단위로 씁니다. |
| 트리거 문장 | 소설의 분위기가 바뀌기 시작하는 지점의 첫 문장입니다. 앞뒤 문장들의 의미가 얼마나 달라지는지를 계산해서 찾아내며, 이 계산은 AI 레포가 미리 수행합니다. |
| 장면(scene) | 어떤 트리거 문장부터 다음 트리거 문장 직전까지 이어지는 문장들의 묶음입니다. 하나의 장면은 하나의 분위기를 가진다고 보고, 음악은 장면 단위로 고릅니다. |
| 캡션(caption) | 장면에 어울리는 음악을 짧은 영어 문장으로 묘사한 글입니다. 예를 들어 "slow, melancholic solo piano"와 같은 글이며, 언어 모델이 장면을 읽고 작성합니다. 소설 문장을 그대로 쓰지 않고 캡션을 거치는 까닭은, 임베딩 모델이 소설 문체가 아니라 음악을 묘사하는 글로 학습되었기 때문입니다. |
| 직접 언급 장면 | 작중 인물이 듣거나 이야기하는 특정 곡의 제목이나 아티스트가 본문에 실제로 적혀 있는 장면입니다. |
| 지정 곡 | 직접 언급 장면에서 언급된 바로 그 곡이 우리 음악 목록에 있을 때, AI 레포가 그 장면에 연결해 둔 곡입니다. |

## 음악과 관련된 용어

| 용어 | 뜻 |
| --- | --- |
| 곡(track) | 음원 파일 하나에 해당하는 음악 한 곡입니다. |
| 구간(segment) | 곡 하나를 수십 초 길이로 잘라 낸 조각입니다. 한 곡 안에서도 분위기가 달라질 수 있으므로, 곡 전체가 아니라 구간마다 따로 임베딩을 만듭니다. |
| 오브젝트 저장소 | 음원처럼 용량이 큰 파일을 보관하고, 인터넷 주소로 내려받을 수 있게 해 주는 저장 서비스입니다. Google Cloud Storage나 Amazon S3가 여기에 해당합니다. |
| 서명된 주소(presigned URL) | 비공개로 보관된 파일을 정해진 시간 동안만 받을 수 있게 해 주는 임시 주소입니다. 주소 안에 만료 시각과 위조를 막는 서명이 들어 있어서, 시간이 지나거나 주소를 고치면 쓸 수 없습니다. 백엔드가 곡을 골라 줄 때마다 새로 발급합니다. |

## 추천과 관련된 용어

| 용어 | 뜻 |
| --- | --- |
| 임베딩(embedding) | 글이나 소리의 의미를 수백 개의 숫자로 이루어진 목록으로 바꾼 것입니다. 의미가 비슷한 대상일수록 숫자 목록도 서로 비슷해지도록 만들어집니다. |
| 벡터(vector) | 임베딩을 이루는 숫자 목록 그 자체를 가리키는 말입니다. 이 문서들에서는 임베딩과 같은 뜻으로 씁니다. |
| 임베딩 모델 | 글이나 소리를 임베딩으로 바꿔 주는 AI 모델입니다. 우리는 글과 음악을 같은 기준의 숫자 목록으로 바꿔 주는 모델인 MuQ-MuLan과 LAION-CLAP을 씁니다. 서로 다른 모델이 만든 임베딩끼리는 비교할 수 없습니다. |
| 차원 | 임베딩 하나를 이루는 숫자의 개수입니다. MuQ-MuLan과 LAION-CLAP은 모두 512차원입니다. |
| 벡터 검색 | 어떤 벡터와 가장 비슷한 벡터들을 데이터베이스에서 찾아내는 일입니다. 우리 서비스에서는 장면의 벡터와 가장 비슷한 음악 구간의 벡터를 찾는 데 씁니다. |
| 코사인 유사도 | 두 벡터가 얼마나 비슷한 방향을 가리키는지를 나타내는 값입니다. 1에 가까울수록 비슷하다는 뜻입니다. |
| top-k | 비슷한 순서로 정렬했을 때 위에서부터 k개를 뜻합니다. k는 설정값으로 정하는 개수입니다. |
| 샘플링 | 여러 후보 가운데 하나를 확률에 따라 뽑는 일입니다. 항상 1등만 고르지 않고 상위 후보 중에서 뽑기 때문에, 같은 장면을 다시 읽어도 다른 곡이 나올 수 있습니다. |
| 선곡 방식(strategy) | 장면에 틀 곡을 고르는 방법입니다. 임베딩으로 고르는 방식, 무작위로 고르는 방식, 아무 곡도 틀지 않는 방식이 있으며, 평가에서 서로 비교하기 위해 여러 방식을 둡니다. |
| 선곡 기록(recommendation) | 어떤 사용자에게, 어떤 장면에서, 어떤 방식으로, 어떤 곡을 골라 주었는지를 남긴 기록 한 건입니다. |
| 자동 재생 쉬는 시간 | 사용자가 중단 버튼을 누른 뒤, 서비스가 새 곡을 스스로 틀지 않고 기다리는 시간입니다. 사용자와 책의 쌍마다 따로 적용되므로, 한 책에서 중단하더라도 다른 책에는 영향을 주지 않습니다. |

## 시스템과 관련된 용어

| 용어 | 뜻 |
| --- | --- |
| 오프라인 배치 | 사용자의 요청을 받는 그 순간에 처리하지 않고, 미리 한꺼번에 계산해 두는 작업 방식입니다. |
| 런타임 | 서비스가 실제로 켜져서 사용자의 요청을 처리하고 있는 동안을 가리킵니다. |
| 모델 서빙 | AI 모델을 서버에 올려 두고, 요청이 올 때마다 모델을 실행해서 결과를 돌려주는 일입니다. |
| 산출물 묶음(bundle) | AI 레포가 분석을 마치고 내놓는 결과 파일들을 zip 파일 하나로 묶은 것입니다. 책 묶음과 음악 묶음 두 종류가 있습니다. |
| 적재 | 산출물 묶음의 내용을 검사한 다음 데이터베이스에 넣는 일입니다. |
| 허용 목록 | 서비스에 들어올 수 있는 사람들의 Google 이메일 주소 목록입니다. 목록에 없는 계정은 로그인을 해도 서비스를 쓸 수 없습니다. |
| 로그인 상태(login session) | 사용자가 Google 로그인에 성공한 때부터 로그아웃하거나 기한이 지날 때까지 유지되는 인증 상태입니다. 브라우저의 쿠키와 `login_sessions` 테이블로 관리합니다. |
| 포트(port) | 백엔드의 핵심 로직이 바깥 세계(데이터베이스, 저장소, 로그인 서비스 등)에 기대하는 기능을 적어 둔 약속입니다. 코드에서는 메서드 이름과 입출력만 선언한 인터페이스로 표현합니다. |
| 어댑터(adapter) | 포트의 약속을 특정 기술로 실제로 구현한 코드입니다. 예를 들어 "벡터 검색" 포트를 PostgreSQL로 구현한 코드가 어댑터입니다. 어댑터만 바꾸면 핵심 로직을 고치지 않고도 기술을 교체할 수 있습니다. |
| SPA | 브라우저가 화면 전체를 한 번 내려받은 뒤, 페이지를 옮길 때마다 서버에서 새 화면을 받지 않고 스스로 화면을 바꾸는 웹 앱 방식입니다. 우리 프론트엔드가 이 방식입니다. |

> "세션"이라는 말은 여러 가지 뜻으로 읽힐 수 있습니다. 따라서 문서에서는 "세션"을 단독으로 쓰지 않고 "로그인 상태"라고 씁니다.
